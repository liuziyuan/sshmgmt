## 3. 按依赖排序的执行步骤

> 每步格式：动哪个文件的哪个方法 / 行为变化 / 验证。**每步末的验证命令必须真实执行并记录结果**（本计划阶段不执行，实现阶段逐步执行）。

### 步骤 1：新增 `src/components/tunnelEditorForm.ts`（纯逻辑，无 React 依赖）

文件内按序落盘（互相无依赖冲突，一次写全；tsc 全文件检查）：

1. **类型**：`ForwardRow { localPort/remoteHost/remotePort: string }`、`EditorFormState { jumpUser/jumpHost/jumpPort: string; forwards: ForwardRow[]; bindAll: boolean; identityFile: string }`（端口用 string 承载 input 中间态，方案 §2.1）、`FormFieldError { field: string; message: string }`、`FormToCommandResult = { ok: true; command: string } | { ok: false; errors: FormFieldError[] }`（方案 §3.1 result 类型，不产出半残命令）。
2. **`EMPTY_FORM_STATE`**：jumpPort="22"、forwards=1 条空行、其余空/false。
3. **`stripHostBrackets(host: string): string`**：剥首尾 `[` `]`（方案 §3.2 规则 7 的输入 normalize）。
4. **`validateFormState(s): FormFieldError[]`**：方案 §2.2 全表——jumpUser 非空/无空格（field="jumpUser"）；jumpHost 非空/无空格/无 `@`（field="jumpHost"）；jumpPort 整数 1–65535（field="jumpPort"）；forwards≥1（field="forwards"）；每条 localPort/remotePort 整数 1–65535（field=`forwards[i].localPort` / `forwards[i].remotePort`）、remoteHost 非空/无空格/无 `:`（field=`forwards[i].remoteHost`）；identityFile 不含 `"`（field="identityFile"，含空格合法）。内部端口解析用 `/^\d+$/` + Number + 整数/范围判断。
5. **`formToCommand(s): FormToCommandResult`**：先 validate（非空 errors 即返回 ok:false）；通过后按方案 §3.1 模板拼装：`ssh` → `-g`（bindAll）→ `-p`（数值≠22 才拼）→ `-i`（trim 后非空；`/\s/.test(path)` 则 `"${path}"` 包裹）→ 逐条 `-L ${localPort}:${remoteHost}:${remotePort}`（分离式）→ destination（`jumpHost.includes(":")` ? `user@[host]` : `user@host`）；`parts.join(" ")`。
6. **`configToFormState(cfg: TunnelConfig): EditorFormState`**：`jump_user/jump_host` 原样、`String(jump_port)`、forwards 深拷贝重命名（`String(local_port)/remote_host/String(remote_port)`）、`bind_all`、`identity_file ?? ""`（方案 §4）。

顶部仅 `import type { TunnelConfig } from "../types.ts"`（`.ts` 后缀 + type-only：tsconfig `allowImportingTsExtensions` 合法，node 类型剥离直跑兼容）。注释英文、无中文字符串（本文件无 UI 文案；校验错误消息为 UI 文案，**用中文**——方案 §9 红字文案即出自这里）。

**验证**：`npx tsc --noEmit` → 0 error（新文件被 tsconfig include ["src"] 覆盖，未引用也检查）。
