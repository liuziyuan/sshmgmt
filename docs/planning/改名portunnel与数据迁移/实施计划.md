手动沙箱（步骤 19，B1/B2/B3 一次完成）：

```bash
# 前置：worktree 根已跑过 npm run build 与 cargo build，二进制为 src-tauri/target/debug/portunnel
SB=$(mktemp -d /tmp/portunnel-smoke.XXXXXX)
mkdir -p "$SB/Library/Application Support/sshmgmt"
cat > "$SB/Library/Application Support/sshmgmt/tunnels.json" <<'JSON'
[{"id":"smoke-1","name":"冒烟隧道","raw_command":"ssh -L 13306:db:3306 u@jump","jump_user":"u","jump_host":"jump","jump_port":22,"forwards":[{"local_port":13306,"remote_host":"db","remote_port":3306}],"bind_all":false,"identity_file":null,"auto_reconnect":false,"group":"GI","environment":"PROD"}]
JSON
printf '["GI"]' > "$SB/Library/Application Support/sshmgmt/group_order.json"
printf '["GI"]' > "$SB/Library/Application Support/sshmgmt/collapsed_groups.json"
shasum -a 256 "$SB/Library/Application Support/sshmgmt/"*.json > /tmp/portunnel-legacy-before.sha
HOME="$SB" src-tauri/target/debug/portunnel
```

B1 判定：界面显示「冒烟隧道」、分组 `GI`、`GI` 折叠状态生效；新目录出现三个 JSON。
B2 判定：`shasum -a 256 -c /tmp/portunnel-legacy-before.sha` 全部 `OK`；旧目录仍在。可选复验：安装 1.2.0 包指向同一 HOME，列表照旧（需下载旧版，属于可选人工项）。
B3 判定：另起空沙箱 `SB3=$(mktemp -d /tmp/portunnel-smoke-b3.XXXXXX)`，`HOME="$SB3" src-tauri/target/debug/portunnel`，在界面新增一条隧道后，`ls "$SB3/Library/Application Support/portunnel/"` 出现 `tunnels.json`，且不存在 `sshmgmt/`。

## 5. 实施风险（≤3）

| 风险 | 影响 | 缓解 |
|---|---|---|

| 手动冒烟误操作真实数据目录 | 高：污染用户配置 | 冒烟一律使用 `mktemp` + `HOME` 沙箱；禁止对真实 `~/Library/Application Support/sshmgmt` 做任何写操作 |
